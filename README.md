### Projetos em destaque

**[Diagnóstico de Rede (web)](https://github.com/filipebrum1516-max/diagnostico-rede-web)**
Aplicação em TypeScript que realiza o diagnóstico de conexões de internet diretamente no navegador (latência, jitter, perda, DNS, download e upload), identifica a causa provável do problema e gera relatório para chamados de suporte.
Acesse: [diagnostico-rede-web.vercel.app](https://diagnostico-rede-web.vercel.app)

**[Diagnóstico de Rede (Python)](https://github.com/filipebrum1516-max/diagnostico-rede)**
Ferramenta de linha de comando que automatiza o roteiro de diagnóstico do suporte técnico: gateway, ping, DNS, portas, traceroute e velocidade, com testes automatizados no Windows e no Linux.

**[VetFlow](https://github.com/filipebrum1516-max/VetFlow1.0For404)**
Sistema de gestão para clínicas veterinárias desenvolvido em TypeScript.
